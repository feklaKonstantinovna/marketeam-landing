# Marketeam landing

Single-page React + Vite hero for the Marketeam marketing talent platform.

## Run

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## What’s included

- Full-viewport hero with background image
- Header with underline nav + rotating conic-gradient CTA
- Urbanist typewriter headline (black / white split) and purple cursor
- Start Project button + “David” cursor badge
- Four concentric spinning orbits with avatars, glows, and 20k+ count-up
- Infinite partner logo ticker
- Responsive breakpoints at 1280 / 1024 / 768 / 480
